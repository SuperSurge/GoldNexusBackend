# 智能客服功能说明

## 功能概述

智能客服系统支持用户与管理员之间的一对一文字沟通：
- 用户端：可向管理员发送消息、查看历史聊天记录
- 管理员端：可查看所有发起过对话的用户列表、查看与指定用户的聊天记录、回复用户消息
- 消息持久化存储，用户重新打开页面仍可看到过往对话

---

## 数据库建表语句

在 `goldnexus` 数据库中执行以下 DDL：

```sql
CREATE TABLE IF NOT EXISTS customer_service_message (
    id           INT AUTO_INCREMENT PRIMARY KEY COMMENT '消息主键',
    user_id      INT          NOT NULL COMMENT '用户ID',
    admin_id     INT          NULL     COMMENT '回复的管理员ID，用户发送时为NULL',
    sender_role  VARCHAR(10)  NOT NULL COMMENT '发送者角色: USER / ADMIN',
    content      TEXT         NOT NULL COMMENT '消息内容',
    is_read      TINYINT      NOT NULL DEFAULT 0 COMMENT '是否已读: 0-未读 1-已读',
    created_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '发送时间',

    INDEX idx_user_id (user_id),
    INDEX idx_user_read (user_id, is_read)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='智能客服消息表';
```

## API 接口文档

### 用户端接口

**基础路径**: `/goldnexus/user/cs`

所有接口需要携带 JWT Token（Header: `Authorization: Bearer <token>`），角色为 USER。

#### 1. 发送消息

```
POST /goldnexus/user/cs/send
Content-Type: application/json

请求体:
{
    "content": "我想咨询一下贷款申请的问题"
}

成功响应:
{
    "code": 200,
    "msg": "发送成功",
    "data": null
}
```

#### 2. 获取聊天记录

```
POST /goldnexus/user/cs/history
Content-Type: application/json

请求体: (空，自动识别当前登录用户)

成功响应:
{
    "code": 200,
    "msg": "查询成功",
    "data": [
        {
            "id": 1,
            "user_id": 2,
            "admin_id": null,
            "sender_role": "USER",
            "content": "我想咨询一下贷款申请的问题",
            "is_read": 1,
            "created_time": "2026-06-28T10:30:00"
        },
        {
            "id": 2,
            "user_id": 2,
            "admin_id": 1,
            "sender_role": "ADMIN",
            "content": "您好，请问有什么可以帮您的？",
            "is_read": 1,
            "created_time": "2026-06-28T10:32:00"
        }
    ]
}
```

### 管理员端接口

**基础路径**: `/goldnexus/admin/cs`

所有接口需要携带 JWT Token，角色为 ADMIN。

#### 1. 获取用户列表（对话摘要）

```
POST /goldnexus/admin/cs/userList
Content-Type: application/json

请求体: (空)

成功响应:
{
    "code": 200,
    "msg": "查询成功",
    "data": [
        {
            "user_id": 2,
            "username": "zhangsan",
            "name": "张三",
            "last_message": "我想咨询一下贷款申请的问题",
            "last_time": "2026-06-28T10:30:00",
            "unread_count": 1
        }
    ]
}
```

#### 2. 查看与指定用户的聊天记录

```
POST /goldnexus/admin/cs/history
Content-Type: application/json

请求体:
{
    "userId": 2
}

成功响应: (与用户端 history 格式相同)
{
    "code": 200,
    "msg": "查询成功",
    "data": [...]
}

注意: 调用此接口后，该用户的未读消息会自动标为已读。
```

#### 3. 回复用户

```
POST /goldnexus/admin/cs/send
Content-Type: application/json

请求体:
{
    "userId": 2,
    "content": "您好，请问有什么可以帮您的？"
}

成功响应:
{
    "code": 200,
    "msg": "回复成功",
    "data": null
}
```

## 业务流程

```
用户端                              管理员端
  │                                   │
  ├─ 发送消息 ──────────────────────►  │  (存入DB, senderRole=USER, isRead=0)
  │                                   │
  │                                   ├─ 刷新用户列表 (看到未读标记)
  │                                   ├─ 点击用户, 查看聊天记录 (消息标为已读)
  │                                   ├─ 输入回复 ──────────────────────► (存入DB, senderRole=ADMIN)
  │                                   │
  ├─ 刷新页面 ◄────────────────────── │  (看到管理员回复)
  │                                   │
```

## 注意事项

1. **权限控制**：用户端接口仅 USER 角色可访问，管理员端接口仅 ADMIN 角色可访问（由 Spring Security + JWT 保证认证，Service 层 `SecurityContextHelper.isAdmin()` 保证授权）。
2. **未读标记**：管理员调用 `history` 接口后，该用户未读消息自动标为已读。`userList` 中的 `unreadCount` 统计的是尚未被管理员点开查看的用户消息数。
3. **线程安全说明**：`CustomerService` 中 `Res` 实例字段的用法沿用了项目现有服务的模式，在生产环境中若需严格线程安全，建议改为局部变量。
4. **WebSocket**：项目已配置 WebSocket 支持（`WebSocketConfiguration.java`），如需实现实时推送新消息通知，可在现有基础上增加 WebSocket 端点，本功能当前基于 HTTP 请求/响应模式实现。
